## Implemented mappings and boundaries

.NET CanonicalLogFields adds @timestamp UTC milliseconds, level, canonical service/environment/instance/version, event_name, request method/template/family/status/duration, valid correlation and active trace/span/parent IDs, error classification and dependency fields. Existing Timestamp/Level/Properties/EventName/Outcome remain available; canonical outcome uses status classification, native Properties.Outcome stays compatible. HttpRequestCompleted maps to http.request.completed, operation terminal aliases to operation.completed and DependencyCompleted to dependency.completed. Unavailable optional fields are omitted; metadata can be unknown and blocks release metadata acceptance.

Immutable release identity is not inferred from an assembly or SNAPSHOT. .NET native ServiceVersion remains unchanged; canonical service_version uses optional trusted Observability:ServiceVersion, otherwise unknown. Quarkus retains native service.version and uses optional APP_VERSION for canonical release identity, otherwise unknown. No environment/config values were set. Quarkus creates a process-lifetime opaque instance when APP_INSTANCE_ID is absent. These identifiers are logs only; metrics and OTel resources are unchanged.

Quarkus native event.name/outcome/service.* stay compatible. Its existing log.schema.version remains native; canonical schema_version is deliberately not stamped onto a partially normalized envelope. P01 requires validation before that stamp, and the existing top-level outcome cannot be silently reinterpreted while current readers still consume it. Canonical event_name aliases failed HTTP completion; duration/status stay numeric; legacy native failure remains failure until a compatibility-aware normalized reader classifies it using status, as required by P01 section 1. The offline [fixtures](p02-fixtures/requests.json) demonstrate that normalized view; they are not an installed Fluent Bit adapter. Zero trace IDs and legacy response IDs are not promoted into canonical trace fields. Early wildcard routes map to /unmatched in the canonical field; matched route templates are retained. A disconnect without an observed response no longer invents canonical status.

Gateway changes are isolated in gateway/nginx.p02.conf, which is not referenced by Compose; the existing gateway/nginx.conf is restored to Git-equivalent preflight HEAD content with the existing autocrlf checkout convention because it is a declared bind source. The frontend config is image-build input in inspected Compose. No runtime activation was performed.

Nginx candidate logs contain native canonical-compatible fields with unknown deployment metadata. Stock Nginx fixed-point request_time is converted by bounded regex decomposition to numeric duration_ms without a new module. $time_iso8601 remains the native timestamp (may include offset and no fractional precision); fixture normalization converts it to UTC milliseconds. Nginx does not claim schema_version=1, complete metadata or span context. Upstream status/timing are bounded diagnostic strings because Nginx may use '-' or lists; no remote addresses/headers/URLs. The two proxy log maps are independent of routing and rate-limit maps.

## Ownership, severity and operations

.NET CorrelationIdMiddleware owns the HTTP terminal summary; MediatR owns separate operation terminal events; GlobalExceptionHandler owns safe unexpected stack diagnostics. The JWKS handler owns one actual HTTP retrieval summary, never a cache-hit/fake fetch event. Quarkus CorrelationIdFilter owns request terminal events; OperationLog/VocabularyOperationLog retain their transaction-completion ownership and nested suppression. Central SafeExceptionLog owns ERROR stack detail; request failure summaries are WARN. Started/slow events are distinct non-terminal diagnostics, not additional completions. Business logs remain named and aggregated.

No new background job was invented. Existing Quarkus retention worker, rotation, file/console async queues and overflow=discard remain unchanged. Serilog synchronous unbuffered I/O is pre-existing and unchanged; no lossless/exactly-once promise. P03 must measure buffer/rotation/loss behavior. No metrics labels, traces/exporters, alert rules, data stores, retention or Grafana/OpenSearch resources changed.
